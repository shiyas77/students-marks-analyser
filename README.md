# Student Marks Analyzer

A beginner-friendly Python project that analyzes student marks and generates a simple report.

## Features
- Accepts student name and marks
- Calculates total and average
- Finds highest and lowest marks
- Assigns a grade based on average
- Validates user input

## Technologies
- Python 3
- Functions, lists, loops, and conditional statements

## How to Run

1. Install Python 3.
2. Open a terminal in this project folder.
3. Run:

   python main.py

## Learning Goals

This project helped me practise Python functions, lists,
loops, conditions, and input validation.
